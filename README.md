# Brouillon

A fast, local-first text editor written in Rust. Free, open source (MIT).
No account, no telemetry.

> Status: **alpha**. Windows x64 builds only. macOS and Linux are planned, not released.
> Builds are not yet code-signed; verify the SHA-256 published with each release.

Français : [brouillon.rochetta.fr/fr/](https://brouillon.rochetta.fr/fr/)
Website: [brouillon.rochetta.fr](https://brouillon.rochetta.fr)

## What it is

- A small, quick-starting editor for code and text, with syntax highlighting, tabs,
  a command palette, find and replace (including across files), a hex view and
  crash recovery.
- Two presets in one binary: a familiar menu-and-toolbar layout, and a
  keyboard-first one.
- Optional, off by default: Brouillon Link, a local MCP server that lets an AI agent
  you allow read (and propose edits to) your open documents, with a consent dialog
  and a secrets filter. Experimental remote editing (SFTP, FTPS) is also available.
- An importer for settings, themes, snippets and file-type definitions from other
  editors.

## Install

Download a build from the project website or the GitHub releases page and follow
[docs/INSTALL.md](docs/INSTALL.md): portable zip (no install, nothing written outside
its folder) or a per-user installer. Package-manager manifests (winget, Scoop,
Homebrew) are generated by [packaging/](packaging/) and will be listed in the
install guide once published.

## Privacy promise

- No telemetry, no analytics, no account. Works fully offline.
- The only request the editor makes on its own is a signed update check at start-up
  (two plain GETs, no identifier, no cookie). Turn it off on the first-run screen,
  with `updates.check = false`, or with the environment variable `BROUILLON_NO_UPDATE=1`.
- Everything else that touches the network happens only when you ask for it
  (connecting to a server you configured, or allowing an AI agent).

The full table of what can leave your machine, to whom and when:
[docs/SECURITY.md](docs/SECURITY.md). To report a vulnerability, see
[SECURITY.md](SECURITY.md).

## Build from source

The Rust workspace lives in `_bmad-output/build/poc-floem` (a historical path kept so
that relative paths in the build scripts stay valid).

```powershell
# Rust stable, 1.91 or newer (rust-toolchain.toml selects stable with rustfmt and clippy)
cd _bmad-output/build/poc-floem
cargo build --release          # target/release/brouillon.exe
cargo test --workspace
```

The remote-editing helper (`brouillon-remote`) is a separate workspace in
`_bmad-output/build/remote-helper`. Release packaging (installer, portable zip,
SHA-256 sums, update manifest): `packaging/build-release.ps1`, described in
[packaging/README.md](packaging/README.md). The landing page source is in
[site/](site/README.md).

## Repository layout

| Path | Content |
|---|---|
| `_bmad-output/build/poc-floem/` | main Rust workspace (`crates/`, `vendor/floem`, `benches/`, `tools/smoke`) |
| `_bmad-output/build/remote-helper/`, `docs-helper/` | separate workspaces for the remote-editing and document helpers |
| `docs/` | install, security, signing, testing and protocol notes |
| `packaging/` | installer, portable zip, package-manager manifests |
| `site/` | static website source |
| `assets/`, `tools/` | brand assets, screenshots, asset and icon generators, update-signing public key |
