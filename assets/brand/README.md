# Brouillon brand assets

Source of truth: `brouillon-icon.svg` (blue bar = the human cursor, hollow violet outline = the agent's ghost cursor).
`brouillon-icon-small.svg` is the heavier variant for 16 to 32 px. Everything else is generated by `tools/icons` (see its README); do not edit PNG/ICO by hand.

| File | Use |
| --- | --- |
| `brouillon.ico` | Windows exe resource, installer, shortcuts (wired: `crates/brouillon/build.rs`, `packaging/windows/brouillon.iss`) |
| `brouillon-{16..1024}.png` | general purpose PNGs |
| `brouillon.iconset/` | macOS, see below |

## Wiring the other platforms (not done, not verified)

- **Linux (hicolor)**: install `brouillon-<n>.png` as `/usr/share/icons/hicolor/<n>x<n>/apps/brouillon.png` for 16, 32, 48, 64, 128, 256, 512, plus `brouillon-icon.svg` as `hicolor/scalable/apps/brouillon.svg`. Reference it with `Icon=brouillon` in the `.desktop` file. For an AppImage, put `brouillon.png` (256) and the `.desktop` file at the AppDir root and a `.DirIcon` symlink to it.
- **macOS**: on a Mac run `iconutil -c icns assets/brand/brouillon.iconset -o brouillon.icns`, then reference it from the app bundle's `Info.plist` (`CFBundleIconFile`). The window icon is set by the bundle, not at runtime.
- **Window icon at runtime** is Windows/Linux only (winit does not support it on macOS); the app loads `window-icon-32.rgba` on every platform and macOS ignores it.
